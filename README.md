#Playwright Automation Framework

A test automation framework built using Python, Pytest, and Playwright for UI and API testing. The framework follows the Page Object Model (POM) design pattern for better maintainability and code reusability.

🚀 Features
UI automation using Playwright
API testing using Python and Pytest
Page Object Model (POM) architecture
Pytest fixtures for setup and teardown
Data-driven testing support
HTML reporting
Reusable utility functions
BDD-style testing using Pytest-BDD
🛠️ Tech Stack
Python
Pytest
Playwright
Pytest-BDD
pytest-html
